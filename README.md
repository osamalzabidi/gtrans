## 🚀 Quick Start

### **Manual Setup & Installation**
```bash
# Clone the repository
git clone https://github.com/osamalzabidi/gtrans.git
cd gtrans

# Install dependencies
pip install flet[all] googletrans

# Run the application
python3 main.py
```
